# Training icons

The Coach uses a shared transparent 4×4 icon atlas at `web/training-icons.png`.
CSS selects cells without altering the source artwork. Labels remain visible;
the icons are decorative and hidden from screen readers. The sheet was created
using the built-in image generation workflow, then revised from user feedback.

| Row | Icons, left to right | Use |
|---|---|---|
| 1 | Stationary cyclist, swimmer, fast runner, weightlifter | Sport/session markers |
| 2 | Moon, gold star, heart, footprint | Rest, completion, cardio load, mechanical load |
| 3 | Calendar, recovery curve, clipboard, import watch | Training calendar, recovery/projections, tests, watch records |
| 4 | Rising bars, warning, target, circular arrows | Conditioning, cautions, goals, weekly review/adaptation |

The rising bars represent conditioning, not connectivity. Circular arrows mean
reviewing and adapting a training plan, not recycling or resetting load.
