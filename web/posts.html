Not needed - COROS already syncs your rides to Strava. This only saves copy-pasting: one button puts the title and caption on that synced ride.

  1. On the Mac, open strava.com/settings/api and create an app (any name, e.g. "S29 Hub"; website http://127.0.0.1).
  2. Set Authorization Callback Domain to 127.0.0.1.
  3. Copy its Client ID and Client Secret here:
Opens Strava to approve. Tick "upload and edit activities".

It never creates a second copy of a ride COROS synced; only if there's no synced copy does it upload the ride (route rides with their map). Strava doesn't let apps add photos, so save the image and add it in the Strava app.
